1. Display: Block

Estos elementos se comportan como bloques de construcción pesados: se apilan uno debajo del otro y ocupan todo el ancho disponible (o el 70% que les fijamos en el CSS).

Bloque A (Ocupo mi propia línea)
Bloque B (Fuerzo el salto de línea)

2. Display: Inline

Aquí tienes un texto común de un párrafo donde queremos resaltar una palabra importante y luego otra frase destacada. Como ves, fluyen de forma natural con el texto. Si miras el CSS, verás que ignoraron por completo el ancho de 300px que intentamos forzarles.

3. Display: Inline-Block

El comportamiento perfecto para un menú de navegación. Los botones se colocan uno al lado del otro, pero respetan el tamaño exacto de 120px que les dimos.

Botón central con display: none

Botón central con visibility: hidden

El botón "Editar" es invisible. Hay un hueco vacío y, por más que hagas clic en ese espacio, no pasará nada.
